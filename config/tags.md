# MVP-0 固定标签词表

三个 Agent 与 SmartSheet 多选字段只允许使用以下标签：

- 亲子活动
- 老人服务
- 买菜生鲜
- 餐饮美食
- 家政服务
- 维修服务
- 社区活动
- 健康活动
- 教育学习
- 文化娱乐
- 运动健身
- 交通出行
- 天气提醒
- 公共服务
- 便民信息
- 优惠促销
- 其他

## 规则

- 禁止 Agent 自行创造同义标签。
- “育儿 / 儿童活动 / 亲子娱乐 / 孩子活动”统一归入“亲子活动”。
- 无法归类时使用“其他”。
- MVP-0 不新增 Tags 表；若需要扩词，先由人工修改本文件，再同步 SmartSheet 选项。
